AppBar কী?
───────────
AppBar হলো Scaffold এর উপরের bar।
প্রতিটা screen এ title, navigation icon, action button
সব কিছু এখানে থাকে।

Structure:
┌──────────────────────────────────────────────────┐
│  [leading]   [  title  ]   [actions...]          │
│──────────────────────────────────────────────────│
│              [bottom / TabBar]                   │
└──────────────────────────────────────────────────┘


══════════════════════════════════════════════════════════════
PART 1 — title (শিরোনাম)
══════════════════════════════════════════════════════════════

AppBar(
  title: Text('My App'),
)

title এ যা যা দেওয়া যায়:
────────────────────────────

► শুধু Text:
  title: Text(
    'My App',
    style: TextStyle(
      fontSize: 20,
      fontWeight: FontWeight.bold,
      color: Colors.white,
      letterSpacing: 1.5,
    ),
  ),

► Image / Logo:
  title: Image.asset('assets/logo.png', height: 40),

► Row — icon + text একসাথে:
  title: Row(
    mainAxisSize: MainAxisSize.min,
    children: [
      Icon(Icons.flutter_dash, color: Colors.white),
      SizedBox(width: 8),
      Text('My App'),
    ],
  ),

► Search bar:
  title: TextField(
    decoration: InputDecoration(
      hintText: 'Search...',
      hintStyle: TextStyle(color: Colors.white70),
      border: InputBorder.none,
    ),
    style: TextStyle(color: Colors.white),
  ),

══════════════════════════════════════════════════════════════
PART 3 — leading (বাম দিকের icon)
══════════════════════════════════════════════════════════════

AppBar(
  leading: IconButton(
    icon: Icon(Icons.menu),
    onPressed: () {
      Scaffold.of(context).openDrawer(); // Drawer খোলো
    },
  ),
)

leading এ যা যা দেওয়া যায়:
─────────────────────────────

► Back button:
  leading: BackButton(color: Colors.white),
  // → Navigator.pop(context) নিজেই call করে।

► Close button:
  leading: CloseButton(),
  // → Dialog বা bottom sheet বন্ধ করার জন্য।

► Custom icon:
  leading: IconButton(
    icon: Icon(Icons.arrow_back_ios),
    tooltip: 'পেছনে যাও',
    onPressed: () => Navigator.pop(context),
  ),

► CircleAvatar / Profile photo:
  leading: Padding(
    padding: EdgeInsets.all(8),
    child: CircleAvatar(
      backgroundImage: NetworkImage('url'),
    ),
  ),

► কিছুই না:
  leading: SizedBox(),
  // → leading এর জায়গা ফাঁকা রাখো।

► leadingWidth দিয়ে leading এর width বাড়ানো যায়:
  leadingWidth: 80,
  leading: TextButton(
    onPressed: () {},
    child: Text('Cancel', style: TextStyle(color: Colors.white)),
  ),

  //   Drawer থাকলে → hamburger (menu) icon দেখায়।

  //   Flutter নিজেই বুঝে নেয়।

  // → false:
  //   কোনো icon দেখাবে না।
  //   leading একদম ফাঁকা থাকবে।
)

PART 5 — actions (ডান দিকের icon গুলো)
══════════════════════════════════════════════════════════════

AppBar(
  actions: [
    // ── সাধারণ icon button ──────────────────────
    IconButton(
      icon: Icon(Icons.search),
      tooltip: 'Search করো',        // ধরে রাখলে hint দেখায়
      onPressed: () {},
    ),

    // ── Notification badge সহ ───────────────────
    Badge(
      label: Text('3'),              // badge এর সংখ্যা
      backgroundColor: Colors.red,
      child: IconButton(
        icon: Icon(Icons.notifications),
        onPressed: () {},
      ),
    ),

    // ── 3 dot Popup menu ────────────────────────
    PopupMenuButton<String>(
      icon: Icon(Icons.more_vert),
      tooltip: 'আরো option',
      onSelected: (String value) {
        if (value == 'settings') { /* settings এ যাও */ }
        if (value == 'logout')   { /* logout করো */ }
      },
      itemBuilder: (BuildContext context) => [
        PopupMenuItem(
          value: 'settings',
          child: Row(
            children: [
              Icon(Icons.settings, size: 18),
              SizedBox(width: 8),
              Text('Settings'),
            ],
          ),
        ),
        PopupMenuDivider(),          // divider line
        PopupMenuItem(
          value: 'logout',
          child: Row(
            children: [
              Icon(Icons.logout, size: 18, color: Colors.red),
              SizedBox(width: 8),
              Text('Logout', style: TextStyle(color: Colors.red)),
            ],
          ),
        ),
      ],
    ),

    // ── Text button ─────────────────────────────
    TextButton(
      onPressed: () {},
      child: Text('Save', style: TextStyle(color: Colors.white)),
    ),

    // ── Switch / Toggle ─────────────────────────
    Switch(
      value: _isDarkMode,
      onChanged: (val) { setState(() { _isDarkMode = val; }); },
    ),
  ],
)

══════════════════════════════════════════════════════════════
PART 8 — elevation ও shadowColor
══════════════════════════════════════════════════════════════

AppBar(
  elevation: 4.0,
  // → AppBar এর নিচে ছায়া কতটুকু পড়বে।
  // → 0    = কোনো ছায়া নেই (flat look)
  // → 4    = default
  // → 10+  = অনেক বেশি ছায়া

  shadowColor: Colors.black,
  // → ছায়ার রং পরিবর্তন করা যায়।
  // → shadowColor: Colors.blue → নীল ছায়া।

  scrolledUnderElevation: 8.0,
  // → Body scroll করলে AppBar এর elevation বাড়ে।
  // → Material 3 এ কাজ করে।
  // → 0 দিলে scroll করলেও elevation বাড়বে না।
)

══════════════════════════════════════════════════════════════
PART 11 — bottom (AppBar এর নিচে TabBar)
══════════════════════════════════════════════════════════════

AppBar(
  bottom: TabBar(
    controller: _tabController,       // TabController লাগবে

    tabs: [
      Tab(icon: Icon(Icons.home),    text: 'Home'),
      Tab(icon: Icon(Icons.search),  text: 'Search'),
      Tab(icon: Icon(Icons.person),  text: 'Profile'),
    ],

    labelColor: Colors.white,         // selected tab এর রং
    unselectedLabelColor: Colors.white60, // unselected রং
    labelStyle: TextStyle(fontWeight: FontWeight.bold),

    indicatorColor: Colors.white,     // নিচের line এর রং
    indicatorWeight: 3.0,             // line এর মোটা
    indicatorSize: TabBarIndicatorSize.tab, // tab / label

    isScrollable: true,               // অনেক tab → scroll হবে

    // Custom indicator (box shape):
    indicator: BoxDecoration(
      borderRadius: BorderRadius.circular(10),
      color: Colors.white24,
    ),

    dividerColor: Colors.transparent, // TabBar এর নিচের line সরাও
  ),
)

TabController বানানোর নিয়ম:
──────────────────────────────
class _MyPageState extends State<MyPage>
    with SingleTickerProviderStateMixin {

  late TabController _tabController;

  @override
  void initState() {
    super.initState();
    _tabController = TabController(
      length: 3,      // tab সংখ্যা
      vsync: this,
      initialIndex: 0 // শুরুতে কোন tab selected
    );
  }

  @override
  void dispose() {
    _tabController.dispose(); // memory leak এড়াতে
    super.dispose();
  }
}

TabBar এর সাথে TabBarView:
────────────────────────────
body: TabBarView(
  controller: _tabController,
  children: [
    HomeScreen(),
    SearchScreen(),
    ProfileScreen(),
  ],
),

PART 18 — clipBehavior
══════════════════════════════════════════════════════════════

AppBar(
  clipBehavior: Clip.antiAlias,
  // → AppBar এর ভেতরের content কীভাবে clip হবে।
  // → Shape দেওয়া থাকলে এটা দেওয়া দরকার নাহলে

══════════════════════════════════════════════════════════════
BONUS — SliverAppBar (scroll করলে লুকিয়ে যায়)
══════════════════════════════════════════════════════════════

CustomScrollView(
  slivers: [
    SliverAppBar(
      title: Text('My App'),
      pinned: true,       // scroll করলেও AppBar থাকবে
      floating: false,    // উপরে scroll করলে দ্রুত দেখাবে
      snap: false,        // floating: true হলে কাজ করে
      expandedHeight: 200.0, // সর্বোচ্চ উচ্চতা

      flexibleSpace: FlexibleSpaceBar(
        title: Text('My App'),
        background: Image.asset('assets/bg.jpg', fit: BoxFit.cover),
        collapseMode: CollapseMode.parallax, // parallax scroll effect
      ),
    ),

    SliverList(
      delegate: SliverChildBuilderDelegate(
        (context, index) => ListTile(title: Text('Item $index')),
        childCount: 30,
      ),
    ),
  ],
)

pinned vs floating vs snap:
─────────────────────────────
pinned: true, floating: false → scroll করলে ছোট হয়, কিন্তু থাকে
pinned: false, floating: true → উপরে scroll করলে দ্রুত আসে
pinned: true, floating: true  → সবসময় থাকে + উপরে scrollে দ্রুত আসে
snap: true (floating লাগবে)  → অর্ধেক দেখা গেলে পুরোটা এসে যায়
